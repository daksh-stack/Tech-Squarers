{% comment %} Text link with an arrow. On hover (and keyboard focus) the colour shifts, an underline wipes in from the left, and the arrow tilts up 45°. Touch screens have no hover, so there the underline is always shown to mark it as a link. Ported from the Hyperiux Vault link-button (React + lucide). The React version swaps its label and tracks taps in JS for touch screens; here CSS covers that, so there is no script. Sizes are rem instead of vw so the text follows the user's font size and zoom. Colours: default vibrant-blue, deep-navy on hover — for light backgrounds. Vibrant-blue needs a near-white background at this weight: on the pale ice-blue tones it drops just under 4.5:1. dark white (ice-blue on hover, white focus ring) — for dark backgrounds, like the home hero. Vibrant-blue on deep-navy is only ~2.7:1, so it can't be used there.
